Administrador Geral (Exclusivo)

Área restrita ao organizador responsável. Somente o Administrador Geral pode configurar a nuvem do GitHub, resetar o sorteio ou restaurar PINs.

🌐 Configurar Sincronização Online (Para funcionar entre vários celulares no GitHub)

⚠️ Apenas Local (Sem Nuvem)

O GitHub Pages hospeda o site gratuitamente, mas por ser estático ele precisa de um banco de dados gratuito na nuvem (Firebase Firestore) para que quando você sortear no seu celular, o celular da sua esposa e dos familiares atualize na mesma hora!

1️⃣ Criar Projeto Gratuito Acesse console.firebase.google.com, clique em "Criar um projeto" (pode desativar o Google Analytics) e depois no ícone Web </>.
2️⃣ Ativar Banco Firestore No menu lateral, vá em Criação → Firestore Database → Criar banco de dados e escolha "Iniciar no modo de teste" (permite leitura e gravação imediata).
3️⃣ Colar o firebaseConfig Abaixo Copie o bloco const firebaseConfig = { ... }; gerado pelo Firebase e cole na caixa abaixo.
4️⃣ Baixar index.html e Subir no GitHub Clique em "Baixar index.html Pronto para GitHub" e substitua o arquivo index.html no seu repositório do GitHub!
